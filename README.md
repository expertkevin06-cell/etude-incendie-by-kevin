# Etude incendie by Kevin
PWA/APK Android • Windows • iOS — base experte des départs d'incendie véhicules & bâtiments 2018-2026.

## Contenu
- 🎯 Zone de départ (foyer) : 10 étapes sapiteur + photos réelles
- 🔋 Feu VE : 8 phases départ→propagation→ré-ignition
- ⚖️ Comparatif électrique VS mécanique VS fluide (8 critères)
- 🌫️ FAP/catalyseur : mécanisme 600-1200°C + preuves
- 🚨 300+ pannes/rappels (NHTSA, Rappel Conso, Safety Gate, SAMR, KBA) dont Skoda Elroq (36 fiches) et 32 modèles 2024-2026
- 🔎 Recherche unifiée prédictive + 4 cases énergie + live 24 sites + IA Gemini
- 🔐 Accès admin (hash) / tiers (ntfy, notification APK, accord-refus-révocation)
- 🔄 MAJ mensuelle automatique (GitHub Action) + validation admin pour les tiers
- 📧 Partage APK par mail • 🖼️ fond admin permanent + opacité • 📶 connexion permanente + hors-ligne massif

## Déploiement
1. Créer le repo `etude-incendie-by-kevin`
2. Envoyer les 15 fichiers (tools/github-push.html ou Create new file)
3. Activer GitHub Pages + Actions (run manuel du workflow)
4. tools/generate-icons.html → 15 PNG → tools/upload-icons-github.html (token)
5. tools/autodiag.html → 0 KO
6. pwabuilder.com → URL Pages → packages Android/Windows/iOS
