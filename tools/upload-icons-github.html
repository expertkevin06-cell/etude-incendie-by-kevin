📤 Envoi icônes + fond sur GitHub

1. Token : GitHub → Settings → Developer settings → Fine-grained tokens → etude-incendie-by-kevin → Contents : Read and write.
2. (Optionnel) placez votre image icône et/ou votre fond (véhicule en feu). Sinon icône intégrée utilisée.
3. Bouton 1️⃣ puis 2️⃣. Supprimez le token ensuite.
